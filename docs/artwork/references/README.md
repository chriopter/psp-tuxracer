# Original PSP hardware references

Downloaded 2026-09-17 for the user-requested PSP-1004 control-guide revision.

- `psp-1004-stefano-palazzo.jpg`: Stefano Palazzo, **SonyPSP.jpg**, explicitly
  identified as Sony PlayStation Portable PSP-1004 by its author/source.
  https://commons.wikimedia.org/wiki/File:SonyPSP.jpg
  Original: https://upload.wikimedia.org/wikipedia/commons/2/21/SonyPSP.jpg
  License: Creative Commons Attribution-ShareAlike 2.5 Generic,
  https://creativecommons.org/licenses/by-sa/2.5/ . Photo retained unchanged.
- `psp-1000-evan-amos.png`: Evan-Amos, **Sony-PSP-1000-Body.png**.
  https://commons.wikimedia.org/wiki/File:Sony-PSP-1000-Body.png
  Original: https://upload.wikimedia.org/wikipedia/commons/5/5d/Sony-PSP-1000-Body.png
  Released into the public domain by the photographer. Supplemental detail
  reference for original-generation hardware; the source labels this a North
  American PSP-1000, not specifically the European PSP-1004.

The runtime guide `ports/extremetuxracer/data/textures/psp-guide.png` is,
since 2026-10-01, Evan-Amos's public-domain photograph itself with a capture
of the game set into its screen (`tools/make-psp-guide.py`); it carries no
further restriction. Stefano Palazzo's photograph is no longer used in any
shipped file and stays here as the reference it was. The superseded generated
revision `../psp-guide-1004-source.png` used both photographs as references
and remains under CC BY-SA 2.5. No claim of endorsement by the photographers
or Sony.
